# 🚗 Honda Car Sales Power BI Dashboard

An interactive **Power BI Executive Dashboard** designed to analyze Honda car sales performance across models, dealers, cities, fuel types, transmission types, and time periods.

## 📊 Dashboard Overview

This dashboard provides a consolidated view of automotive sales performance and helps analyze:

- Total Sales
- Total Revenue
- Profit
- Average Selling Price
- Total Finance Amount
- Average Customer Satisfaction
- Sales by Month
- Profit by Transmission
- Sales by Car Model
- Sales by Dealer
- Profit by City
- Sales and Profit trends over time
- Sales by Fuel Type

## 🎯 Business Objective

The objective of this project is to transform automotive sales data into an interactive executive-level dashboard that makes it easier to monitor sales performance, profitability, customer satisfaction, and dealership performance.

## 🛠️ Tools & Technologies

- **Power BI**

## 📈 Dashboard Features

### Sales Analysis
Monthly sales trends are visualized to identify changes in sales volume over time.

### Model Analysis
The dashboard compares sales performance across different Honda car models.

### Dealer Analysis
Sales can be analyzed across different dealerships to understand dealer-level performance.

### Profitability Analysis
Profit is analyzed by city and transmission type to provide a deeper view of profitability.

### Customer Analysis
Average customer satisfaction is included as a KPI for monitoring customer experience.

### Fuel & Transmission Analysis
The dashboard provides filters and visualizations for:
- Diesel
- Hybrid
- Petrol
- Automatic
- Manual

## 🎛️ Interactive Filters

Users can interact with the dashboard using filters such as:

- Fuel Type
- Dealer
- Model
- Date / Month

These filters allow users to drill down into specific segments of the sales data.
